# Review methods {#sec:methods}

The review addresses the English PDFs associated with the two cited DOI
records. The repository preserves those editions and their SHA-256 checksums.
Text extracts retain layout and page boundaries so that quotations can be
checked against the page cited. The volume numbers, sections, and pages in the
audit refer to those copies.

The review began with a reading of both volumes. Section-by-section audit
passes recorded 217 raw findings. A separate pass looked for passages that
addressed the criticisms from the author's perspective. Other passes checked
factual claims, bibliographic records, and quotation context. The authorship
disclosure for the referee report names Anthropic's Claude for reading,
drafting, and audit assistance and an OpenAI model for cross-vendor
fact-checking. The archived records identify these as model-assisted passes.

The local verification gate compares the text extracts, restored listings,
derived numbers, and audit cross-references. The triage map preserves the
connection between a raw finding and the corresponding register entry.
